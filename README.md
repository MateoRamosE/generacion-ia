# Generación IA

Proyecto de generación de imágenes, videos y audio mediante modelos de inteligencia artificial ejecutados en GPU NVIDIA en la nube.

## Estructura

- `references/`: imágenes, videos y audios de referencia.
- `results/`: contenido generado.
- `src/`: código fuente para cada tipo de generación.
- `config/`: archivos de configuración.
- `scripts/`: scripts auxiliares.
- `requirements.txt`: dependencias de Python.

## Requisitos

- Python
- GPU NVIDIA compatible con CUDA.
- Plantilla oficial PyTorch de RunPod.

## Instalación

Instalar las dependencias con:

```bash
pip install -r requirements.txt
